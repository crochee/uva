# 行词汇在读边界归一一次，未知类型 fail-closed

ADR-0006 把「一行是什么」收成 `uva-session` 内的行词汇模块，并许下后果：「`carries` 存在，所以标签配对不再在每个读点各写一遍双标签匹配」。兑现的情况是：读点仍在写。`routes/follow.rs:953` 的 `carries_live_content` 只有 `Typed` 分支，旧方言日志里的助手行拿不到回合标签；`routes/tasks.rs:320` 与 `state/app_state/sessions.rs:811` 各自重写了一遍两分支配对。

更根本的原因是：`RowDialect` 是**运行期类别**。每个读点都要自己回答「这一行是当前词汇写的，还是旧方言写的」，于是每个读点都要维护一个两分支 match，而漏掉分支的后果是静默的——`follow.rs:953` 漏掉的就是。

我们把归一移到**读边界**：任意一行在那里被还原成**当前行**，之后没有任何读者分支在方言上。旧行仍然永远可读——可读性与可写性是两件事——但「可读」由一个地方负责，不再由每个读点各自负责。

## 决定

- **归一在读边界发生一次。** 行词汇新增一个把任意一行还原成**当前行**的原语。方言是归一的**输入**，不是运行期类别：`UserInput` → `UserMessage`；`Model` 按 part 种类（文本 / 工具调用 / 推理）→ `AssistantMessage`，工具结果 → `ToolResult`；`Message` **按载荷的 role** → `UserMessage`/`AssistantMessage`/`ToolResult`（宽松的手写 `{"role":…,"content":[…]}` 拼写与当前行同一套宽严）；`Agent` 没有对应物（委派子会话现在有自己的日志），归一时丢弃。角色多态的 `Message` 由载荷判定，是 omp 那个「标签说不是用户消息、载荷说是用户消息」的真缺陷所在。
- **类型化行以标签为准。** 载荷的 role **只在**角色多态的方言上参与判定。其余场景「谁产出的」不靠 role 推——那是正交的事，不在这一刀里。
- **未知类型 fail-closed。** 一行的类型当前构建不认识，且这一行没有「可忽略」标记 ⇒ **这份会话日志读不了**，而不是「跳过这一行」。静默跳过一条必需事件会重建出一个错误的会话；宁可拒读整个日志。拒读是**一个**决定，一处执行。
- **「可忽略」是逐标签声明的**，由会话写入者盖在行的顶层（`type` 的兄弟键），不落在 `SessionEvent` 的变体里。今天的 33 个标签全部不可忽略，所以今天的行为不变；将来新增的标签若丢了也不影响重建，就声明成可忽略，旧构建就能跳过它。标记**始终**是跳过安全性的唯一来源——不靠类型名前缀。
- **表面成员资格进词汇**，公开 `RowTag::surface_role()`；「这一行投影成哪条模型消息」也进词汇。
- **归一跨过语言边界：服务端发布当前行。** 行词汇发布 `publish_row` / `publish_rows`——一行的**当前形状**（当前行原样、旧方言改写成对应物、没有当前形式的行不发布），`sessions/get` 的 `history`、`follow` 的 baseline 与逐帧行都经它发布。浏览器从此不见方言拼写：`SessionTurn.type` 收窄为 33 个标签，Web 的方言分派表与 `SessionRowDialect` 联合随之退场。发布的行是**原始行，只在词汇说它不对的地方改**（标签、载荷拼写、附件引用的位置、失败标志），序号与时间戳连同它们的**缺席**原样保留——不重序列化事件，`SessionEvent` 的必填 `seq` 表达不了「这一行没有序号」。
- **选择谓词不中央化。** 行词汇只发布关于**一行**的原语：还原后的标签、表面成员资格、当前形状。每个读模型自己决定收哪些行——这是 GLOSSARY 已经写着的规矩。
- **转录判据不进词汇。** 「进不进表面」由行词汇声明；「进不进转录」由每个读模型自己决定。词汇级的转录谓词不存在正确的答案：TUI 渲染 `approval_asked` 而 tool-task 不渲染，TUI 丢 `tool_call` 而 tool-task 渲染。
- **标签命名不改。** 33 个平铺 snake_case 标签不动。
- **行词汇内不设 trait。** 归一只有一个 adapter，四个方言是一个封闭 match 的分支，不是可换的实现——seam 是假的。

## 参考

两个参考实现给了不同的答案，我们各取一半：

- **dsh**（`deepseek-ai/deepseek-harness`）把「任意格式」解决在读者的**上游**：格式有版本，迁移链在读时把旧行向前归一，所以没有任何读者分支在旧方言上；遇到不认识的类型就**拒绝整份日志**，除非那行带 `ignorable` 标记——「默认必需，于是忘了标记只会过度拒读（一个不便），而不是静默续上一个被掏空的会话」。我们照搬这两个形状：归一在读边界、未知类型 fail-closed。dsh 的版本链与迁移包我们不照搬：uva 的方言是**冻结的历史**（四个信封），一次归一函数足够，版本链是杀鸡用牛刀。
- **omp**（`oh-my-openagent`）没有词汇 module，行类型是外部包的自由字符串，未知类型被容忍跳过，于是它的消费者各自手搓标签匹配，且已经有真缺陷：`custom_message` 的标签说「不是用户消息」、载荷却是 `role:"user"`。这是我们不走的路，也是「归一要按载荷判定」这条的由来。
- dsh **也没有**解决「每读点选择谓词」——它有 8 处以上重拼同一句。所以「不中央化选择谓词」不是偷懒，是有先例的判断。

## Considered Options

- **保留方言为运行期类别，只加一个「归一化标签」原语**：被否。读点仍然要写 match，只是短了；`follow.rs:953` 那类漏分支的缺陷类型不变。
- **照 dsh 上整套格式版本 + 迁移包**：被否。uva 的方言是冻结的历史，四个信封不需要一条版本链。形状照抄，规模按方言数裁。
- **把选择谓词也收进行词汇**（`is_user_prompt(row)` 这类具名谓词）：被否。每加一个具名谓词，行词汇就多一份消费方策略，与「每个读模型自己决定收哪些行」抵触；而且新增的行词汇成员还要维护。
- **给词汇级的转录谓词**：被否。见上——不存在一个对 TUI 与 tool-task 同时正确的答案。
- **照 omp 容忍未知类型**：被否。静默跳过必需事件会重建出错误的会话。
- **改标签命名为家族前缀**（`compaction/start`）：被否。家族前缀是命名美学不是杠杆来源；它会牵动 5 个 crate、生成的 TS、词法门禁的词表与冻结面。dsh 用前缀是因为它的词汇还在长。

## Consequences

- **冻结面变动**：删 `RowClass`、`RowReading`、`carries`、`classify_row`；增「还原后的一行」「它为何不是当前行」「宽松单行还原」「不可读日志」「表面角色」；`RowTag` / `RowDialect` / `Rows` 保留名字但形状变（`Rows` 的构造从构造即成功变成构造即校验）。按 `AGENTS.md` §3.10 同步 `docs/api-frozen.md` 与 `scripts/frozen-api/baseline`。
- **保证从门禁移到类型**：`check-row-vocabulary` 是纯词法的，它管「你怎么拼一行」，不管「你怎么分类一行」——今天那个两分支 match 对它隐形。「漏掉方言分支」今后不可表达，因为读者见不到方言。
- **两个行为变化随同一刀落地**：旧方言的 `Model` 行现在算「活内容」（`follow.rs`），TUI 与 tool-task 的转录会开始渲染它们今天跳过的旧方言行。这是归一的应有结果，但必须在同一个改动里看得见。
- **跨语言半边的行为变化**（发布落地时）：线上 `history` / `rows` 不再有方言拼写，`Agent` 行与未知行**不发布**（`sessions/events` 的 `legacy` / `unknown` 桶继续报告它们）；带序号的旧方言助手轮从此有评分目标（此前浏览器根本不提供）；`Message` 方言的宽松拼写与 `Model`+推理行此前被**两边静默丢弃**（浏览器的表画得出、词汇判不进），现在还原进表面——旧路径向当前路径看齐。还原事件的 `seq` 修复还让引用方言行真序号的 `compaction` 替换校验通过，上下文计价器对这类旧日志从多算改为算对。
- **新标签的代价**：新增一个**不可忽略**的标签，会让旧构建拒读整份日志。新增标签若丢了也不影响重建，就声明成可忽略——这是写标签的人要做的判断，判错的代价是旧构建读不了新日志。
- **本 ADR 不裁定的**：线上行的载荷字段的类型（`SessionTurn.data` 仍是 `Value`——还原行的载荷已是 provider 消息的拼写，但字段本身不再收窄）；前端转录的折叠语义（Web 按 `min..max` 区间影子、Rust 按被引用的行逐位对账）；插件行的专属命名空间（今天 `RowTag::Plugin` + `data.kind` 已经够用，不另造第二套）。
